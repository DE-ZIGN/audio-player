# 記事について（準備中）

記事は準備中です。このプレイヤーの考え方、ビットパーフェクト、音量とディザ、聴き比べと音量、ABX のやり方から、順に載せていきます。

## この画面について {#reader}

- この画面は記事を読むためだけのもので、プレイヤー本体とは切り離してあります。記事の側から、再生を始めたり、設定を変えたりすることはできません。
- 外部のサイトへのリンクは、この画面では開かず、既定のブラウザーで開きます。
- 広告や閲覧の追跡はありません。この画面は、アプリの外からは何も読み込みません。

## 記事からプレイヤーの画面を開く {#links}

記事には、プレイヤーの画面を開くリンクを置けます。開けるのは次の 3 つの画面だけです。

- [ABX で聴き比べる](app:abx)
- [出力の確認を開く](app:output-check)
- [設定を開く](app:settings)
