# アンプビューの画像（タスク 9-9、`amp/`）

コンセプト画像 `UI-AMP-SE-v1`（真空管が灯った音作りモード）と `UI-AMP-SE-PURE-v2`（真空管が消えた原音モード。前者と画素の位置がそろっている）から、`tools/ui_amp_parts.py` で切り出した画像です。見本は標準ビューと同じく 150% の画面で描いたものとして扱います。

実際に読むのは、その 2 枚から文字だけを消した `UI-AMP-SE-NOTEXT-v1`・`UI-AMP-SE-PURE-NOTEXT-v1` です（ユーザーが画像生成で作成、2026-11-14。つまみ・ランプなどの位置は元の 2 枚と 1 px 以内で一致することを確かめた）。この 2 枚がないときは元の 2 枚を読み、文字もスクリプトで埋めます（`--with-words` でも同じ）。

- 消して、ページが描くもの：パネルの文字、VU メーターの下の L・R、木の帯のバッジの文字（この 3 つは NOTEXT の 2 枚では消えている）、ランプ（点いているものも消えているものも消し、原音版の CLUB の消えたランプを全部のソケットに戻した）、VU メーターの目盛り・数字・針、VOLUME のつまみの指針、木の帯の丸いボタン（2 枚で数も位置も違うため、両方から消してページのボタンを置く）。
- 見本のまま残すもの：つまみの胴、トグルの座金、区切り線、ねじ、真空管、トランス。
- 金属と木目は横向きの筋なので、行ごとに左右の端の色でつなぎ、細かい筋は同じ行の隣から写して埋めた。
- 作り直すときは `python tools/ui_amp_parts.py`（`--src` を省くと `../imagegen/accepted/` を読みます）。

## プッシュプルのアンプ（PP EL34・PP CLASS A）

コンセプト画像 `UI-AMP-PP-v1` から、`tools/ui_amp_pp_parts.py` で切り出した画像です。パネルの配置は SE と違い（MODE・TUBE TYPE・SPACE は押しボタン、CROSSFEED はトグル、木の帯にシャッフルとリピート）、真空管の種類に合わせてアンプごと入れ替えます（ユーザー、2026-11-14）。

- 実際に読むのは、文字を消した見本 `UI-AMP-PP-NOTEXT-v1` と、真空管とメーターの照明を消した見本 `UI-AMP-PP-PURE-NOTEXT-v1` です（ユーザーが画像生成で作成、2026-11-14）。元の `UI-AMP-PP-v1` と部品の位置が 1 px 以内で一致し、2 枚どうしもそろっていることを確かめました。2 枚がないときは `UI-AMP-PP-v1` を読み、文字はスクリプトで埋め、消えた絵の代わりにも灯った絵を使います。
- 消して、ページが描くもの：
  - 押しボタンの文字と点灯（全部を消灯にそろえ、点灯していたボタンの周りの灯りも金属の筋でつないだ。ページが文字を書き、選ばれたものを灯す）
  - つまみの指針
  - VU メーターの目盛り・数字・針
  - バッジの文字
  - 木の帯の丸いボタン
  - パネルの文字と L・R（NOTEXT がないときだけ）
- 見本のまま残すもの：押しボタンの胴、つまみの胴と周りの目盛り、区切り線、ねじ、通風口、真空管。
- 作り直すときは `python tools/ui_amp_pp_parts.py`。
