# アンプビューの画像（タスク 9-9、`amp/`）

コンセプト画像 `UI-AMP-SE-v1`（真空管が灯った音作りモード）と `UI-AMP-SE-PURE-v2`（真空管が消えた原音モード。前者と画素の位置がそろっている）から、`tools/ui_amp_parts.py` で切り出した画像です。見本は標準ビューと同じく 150% の画面で描いたものとして扱います。

- 消して、ページが描くもの：パネルの文字、VU メーターの下の L・R、ランプ（点いているものも消えているものも消し、原音版の CLUB の消えたランプを全部のソケットに戻した）、VU メーターの目盛り・数字・針、VOLUME のつまみの指針、木の帯のバッジの文字、木の帯の丸いボタン（2 枚で数も位置も違うため、両方から消してページのボタンを置く）。
- 見本のまま残すもの：つまみの胴、トグルの座金、区切り線、ねじ、真空管、トランス。
- 金属と木目は横向きの筋なので、行ごとに左右の端の色でつなぎ、細かい筋は同じ行の隣から写して埋めた。
- 作り直すときは `python tools/ui_amp_parts.py`（`--src` を省くと `../imagegen/accepted/` を読みます）。
