# 開発言語とフレームワークの選定（2026-11-06）

（詳細版は作業用の非公開ドキュメント。ここは要約）

> 2026-11-08 決定: ソースを公開するため、JUCE は AGPLv3 で使う（収入の上限なし）。下の Starter などの区分は当時の比較情報。

## 推奨
- C++20 + JUCE 8 を土台、画面は JUCE 8 の WebView UI（WebView2）で TypeScript
- ビットパーフェクトな出力層（排他WASAPI・ASIOへの整数直送、DoP、曲ごとのレート切替）は自前実装
  - 理由: JUCEのデバイス層はDAW向けで、DSD非対応。浮動小数点経由で整数変換係数が2のべき乗でない実装があり、ビットパーフェクトを保証しにくい
- 次点: Rust + Tauri（wasapiクレートで排他・ループバック可。VST3ホストとDSP部品は自前）

## JUCE 8 ライセンス
- Starter: 年間売上・資金2万ドルまで無料 / Indie: 30万ドルまで、月40ドルか買い切り800ドル / Pro: 上限なし、月175ドルか3,500ドル / または AGPLv3（本プロジェクトはこれ）

## 構成案
- 画面（ライブラリ・検索 / 再生画面 / 実機風エフェクトパネル）⇔ JUCEネイティブ連携 ⇔ 音声エンジン（入力元→デコーダー→原音経路 or 64bit音作り経路→自前出力層→DAC、ライブラリDBはSQLite）

## Claude Code での進め方
- リポジトリをエンジン/アプリ本体/画面/テストに分割
- エンジンの出力をファイルに書き出してバイト一致を自動テスト
- 画面は Vite 開発サーバーを WebView で開いて開発
- 調査・企画ドキュメントを要約した CLAUDE.md を置く
