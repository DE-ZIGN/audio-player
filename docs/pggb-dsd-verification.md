# PGGBと高レートDSD・1ビットDACの検証（2026-11-08）

（詳細版は作業用の非公開ドキュメント。ここは要約）

## 結論
- PGGBは宣伝どおり動く本物の変換ソフト。ただし音質向上を示す測定・ブラインドテストは公式になし。Archimago（2021）の差分テストでは一般的な変換（Adobe Audition）との差は可聴帯域で-140dB未満、「魔法の効果の証拠なし」
- DSDについての一般的な評価はおおむね正確だが、1ビットDACを「完璧」「究極」とするのは言い過ぎ（1ビットはジッター・立ち上がり・帯域外ノイズの折り返しに敏感で、主流はマルチレベルへ移行）
- 自作プレイヤーで実現可能。壁はメモリー（曲全体なら16〜32GB）、遅延（100万タップ@705.6kHzで約0.7秒）、DSD512以上はASIOネイティブDSDが必要（WASAPIはDoPのみ、DoPの上限は最大PCMレート×16）
- 精度は64bitで十分（数値ノイズ-360dB）。128/256bitは謳わない

## PGGBの事実（公式）
- オフライン版とPGGB-Live（V9でベータ）。精度64/107/128/256bit。PCM最大3.072MHz、DSD最大DSD2048、変調器5〜25次
- 現行公式にタップ数の記載なし。2021年は6分の曲16倍で2.5億タップ、PGGB 256以降は曲全体を使う方式（作者談）
- 動作条件: オフラインDSD512で8コア24GB、DSD1024/2048で32〜64GB、Live DSDは16コア以上24GB、AVX2必須
- 価格: Lite無料、Plus $350、Pro $650、Max $1,050。商用利用はどの版も不可

## よくある誤り・古い情報
- ノイズシェーピング9〜11次 → 公式は5〜25次
- PGGB-RT → 現行はPGGB-Live
- Holo/Gustard/Cayinを1ビットDACの例に挙げる → Holo MayはPCMがR-2R、DSDは別の抵抗回路。Gustard/Cayinは未確認。確実な例はマランツMMM（PCMを11.2MHz DSDに変換、DSDはバイパスしてアナログFIRでD/A）
- 市販DSDの多くはDXD編集 → 割合は未確認
