# 音作りDSPのモデリング手法と機能候補（2026-11-06）

（詳細版は作業用の非公開ドキュメント。ここは要約）

## 真空管サチュレーション
- 狙いはリスニング向けの薄い色づけ（低次倍音）
- 手法: 波形整形＋前後フィルター（軽い、第2段階の標準）/ 回路モデル（WDF・DK法・ノード解析、第3段階の差別化）/ ニューラル（NAM等、将来の実験枠）
- 折り返し対策: オーバーサンプリング＋ADAAの併用（ADAA＋4倍OSでハードクリップでもほぼ問題なし）。1次ADAAは0.5サンプル遅延

## 空間シミュレーション
- ライブ再現の本命は実在ホールIRの畳み込み（OpenAIR、作品ごとにCCライセンス・帰属表示）
- 可変性はアルゴリズムリバーブ（FDN、Dattorroプレート）＋初期反射（鏡像法）
- ヘッドホン: クロスフィード（bs2b）→ 将来バイノーラル
- 録音に既に響きがあるため、ドライ/ウェット比・プリディレイ・響き側の低域カットが重要

## その他のDSP（優先度）
- 第1段階: デジタル音量＋TPDFディザ、ヘッドルーム管理、トゥルーピークリミッター、ReplayGain 2.0（EBU R128、-18 LUFS）、パラメトリックEQ（直線位相も）、メーター、ABX
- 第2段階: 真空管（波形整形）、畳み込みリバーブ、クロスフィード、リサンプラー、ラウドネス補償EQ、オートレベラー/コンプ（深夜モード等の任意機能）
- 第3段階: 回路モデル、FDNリバーブ、ルームEQ測定、ニューラル、バイノーラル

## 使えるライブラリ（製品組み込み可）
- r8brain-free-src（MIT）、libebur128（MIT）、RTNeural（BSD-3）、NeuralAmpModelerCore（MIT）、Airwindows（MIT）、chowdsp_utils（モジュールごとにBSD/GPLv3）、EffeTune（MIT、参考実装）
- 2026-11-08 追記: ソース公開（AGPLv3）に決めたため、GPLv3 の部品も組み込める。ただし採用前にライセンスを確認し `THIRD_PARTY_NOTICES` に記載する

## 共通ルール
- 64bit処理、ヘッドルーム、非線形はOS＋ADAA、バイパス時ビット一致テスト、パラメータのスムージング、遅延補償、スイープでの倍音・折り返し測定、音量合わせABX

## 検討メモ（2026-11-06）
### 真空管タイプのジャンル別選択
- SE三極管（2次中心・温かい・余裕小）→ アコースティック・ジャズ、ボーカル、室内楽 / PP AB級（3次中心・力強い・低域が締まる）→ ロック、ポップス、オーケストラ / PP A級控えめ → オールラウンド
- ジャンルは初期値。ジャンルタグから自動選択、対応表は利用者が編集、アルバム単位で上書き、切替は音量合わせ＋クロスフェード
- 好みは2次派・3次派・どちらでもない派がほぼ3分の1ずつとの証言あり
- スピーカー制動は再現不可。出力インピーダンス×スピーカーインピーダンス曲線による周波数特性変化をEQで模擬する案

### ホールIR
- 同梱する空間は最低限3種類: 小＝ライブハウス・ジャズクラブ / 中＝コンサートホール / 大＝アリーナ・スタジアム
  - 小: 自由に使える実測が少なく自前生成が本命
  - 中: MAIR（St. Paul's、RT60 2.1秒、CC BY 4.0表記）やOpenAIRのCC BY作品
  - 大: 自由な実測はほぼなし。アルゴリズムで合成。スタジアムはエコーで濁りやすいので屋内アリーナ寄り＋反射量を調整可能に
- 同梱はCC BY系のみ（SA・NCは外す）
- 不可/要交渉: Pori（非商用）、Samplicity Bricasti M7（商用同梱禁止）、EchoThief（同梱は要相談）
- Voxengo IM Reverbs Pack（38種、合成IR、44.1kHz/16bit）: 再配布は無償・無改変・著作権表示付きのみ → 無料配布なので無改変同梱可。ダウンロード先の案内が無難
- 進め方: CC BY候補を一覧化 → 試聴して選ぶ → 不足は生成 → クレジット画面に帰属表示、ユーザーIR読み込みも可能に（候補は `ir-candidates.md`）

### 内部サンプルレート
- 推奨: 曲のレートのまま処理し、倍音を作るエフェクト内だけ局所オーバーサンプリング
- 出力レートは「曲のまま/固定」を選択式（固定はアルバムまたぎ・シャッフルでのDAC切替の無音やノイズ対策）
- 変換は同系列の整数倍優先（44.1→88.2/176.4、48→96/192）、系列またぎは画面に表示、r8brainを使用
- 既定: 原音モードは常に曲のまま、音作りモードは曲のまま＋局所OS
